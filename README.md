# EV Launcher

The small Windows program the EcomVantage team uses with EV Profile Manager.
It opens a client's browser window on your laptop when you click **Open**.

This page holds the installer only. It is for EcomVantage staff: the program
does nothing without an EcomVantage account.

## Install it (one time per laptop)

1. Download it: **[EV-Launcher-Setup.exe](https://github.com/deoecom-vantage/ev-launcher/releases/latest/download/EV-Launcher-Setup.exe)**
2. Open the file you downloaded. If Windows shows a blue box that says
   "Windows protected your PC", click **More info**, then **Run anyway**.
   It shows because the program is our own and not from a big software company.
3. A small sign-in window opens. Sign in with your Hub email and password.
4. That is all. It starts by itself with Windows and sits near the clock.

You need Google Chrome on the laptop.

## A newer version

Download it again from the link above and open it. It replaces the old one.
Close your client windows first.

## What is in the installer

The program, and the address of the EV Profile Manager website. No password,
no key and no client data. Those stay on the server.
